# hosts

| Path | What |
|---|---|
| `frogswamp/default.nix` | The server: host values (user, IP, disk) and which services are enabled |
| `frogswamp/disko.nix` | Disk layout, applied **only** by `just install` (wipes the disk) |
| `frogswamp/secrets.nix` | Which sops secrets exist and which service reads them |
| `frogswamp/facter.json` | Hardware report, regenerated by `just install` on new hardware |
| `frogswamp/vm.nix` | Overrides for `just vm` (no real secrets, DHCP, hardware services off) |
| `installer/default.nix` | Custom installer ISO (`just iso`): your SSH key baked in, reachable as `frogswamp-installer.local` |

## Changing hardware

1. New disk device name? Set `frogswamp.disk` in `frogswamp/default.nix`.
2. Run the "Resetting from scratch" steps in the root README. `facter.json` is regenerated automatically.
3. The static IP matches any wired NIC, so no network change is needed.

## Changing the IP

Edit `frogswamp.lan` in `frogswamp/default.nix`. It must stay outside the router's DHCP pool (`.100–.254`; see the root README prerequisite). Then run `just try` (a reboot undoes it if you lose access), confirm access on the new IP, and run `just deploy`.
